# Toward an Organic-Based ALU — Phase 1

**Status: design hypothesis, not a demonstrated biological ALU.**

Goal: a sub-20-mm engineered biological ALU architecture compatible with a later organic RISC processor. Phase 1 focuses on pA-scale current-mode logic cells, selective electrical interconnects, and fan-out of two.

Two candidate output architectures:
- A: one logic core, two locally separated output drivers.
- B: two locally separated logic regions in the same cell, sharing inputs, each driving one output.

See `PHASE1_REPORT_EN.md` for the English research report and `PHASE1_REPORT.md` for the Turkish report. Both include falsifiable criteria, risks, and literature.

No wet-lab validation has been performed. Laboratory targets are suggestions, not collaborators.
